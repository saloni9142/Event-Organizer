# 📅 Event Organizer Platform

A full-stack Event Organizer web application built using Next.js, Supabase, and Clerk authentication.  
This project allows users to create, manage, and explore events with secure login and database integration.

It was built as part of my learning journey in full-stack development.

---

## 🚀 Features

- 🔐 Authentication using Clerk (Sign up / Login / Logout)
- 🗓️ Create, update, and delete events
- 📋 View all events
- 👤 User-specific event management
- 💾 Supabase database integration (PostgreSQL)
- ⚡ Next.js frontend
- 🌐 Fully responsive UI

---

## ⚙️ Setup Instructions

### 1. Clone repository
git clone https://github.com/saloni9142/Event-Organizer.git
cd Event-Organizer

---

### 2. Install dependencies
npm install

---

### 3. Create .env.local file

NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=your_clerk_key
CLERK_SECRET_KEY=your_clerk_secret

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

---

### 4. Run project
npm run dev

Open:
http://localhost:3000
